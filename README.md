# Задание 1. Задача 3. Имена

### Текст задачи
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество. Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду. Создать имена: Клеопатра, Пушкин Александр Сергеевич, Маяковский Владимир.

### Алгоритм решения
1. Создан класс `Name` с тремя полями: `_surname`, `_firstName`, `_patronymic`.
2. Для доступа к полям используются свойства `Surname`, `FirstName`, `Patronymic`.
3. Созданы конструкторы, принимающие разное количество параметров.
4. В методе `ToString()` происходит проверка каждого поля на пустоту (через `string.IsNullOrEmpty`). Если поле не пустое, оно добавляется к итоговой строке. В конце строка обрезается методом `Trim()`.
