# Задание 1. Задача 3. Имена

### Текст задачи
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество. Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду. Создать имена: Клеопатра, Пушкин Александр Сергеевич, Маяковский Владимир.

### Алгоритм решения
1. Создан класс `Name` с тремя полями (фамилия, имя, отчество).
2. Реализованы конструкторы для создания имен с 1, 2 или 3 параметрами.
3. В методе `ToString()` каждое поле проверяется на пустоту и добавляется в строку только при наличии текста. В конце лишние пробелы удаляются методом `Trim()`.

# Задание 2. Задача 3. Человек с родителем

### Текст задачи
Измените сущность Человек, добавив возможность задавать отца. При приведении к строке: если у человека нет фамилии, и есть отец с фамилией, фамилия берется у отца. Если нет отчества, а у отца есть имя, отчество задается как имя отца + "ович". Создать Чудова Ивана, Чудова Петра, Бориса. Сделать Ивана отцом Петра, а Петра отцом Бориса.

3. В методе `Main` созданы три объекта и выстроена цепочка родства (Иван -> Петр -> Борис).

# Задание 4. Задача 6. Создаем Человека

### Текст задачи
Измените сущность Человек. Новые требования к конструкторам:
- Строка (имя) и рост.
- Строка (имя), рост и отец.
- Объект Имя и рост.
- Объект Имя, рост и отец.
Операции присвоения должны использоваться только в одном конструкторе. Создать: Льва (строка, 170); Пушкина Сергея (Имя, 168, отец Лев); Александра (строка, 167, отец Сергей).

### Алгоритм решения
1. Создан один главный конструктор, который принимает имя, рост и отца. В нем происходят все сохранения данных.
2. Остальные конструкторы ничего не сохраняют. Они вызывают главный конструктор через `this()`, преобразуя строку в объект `Name` при необходимости.
